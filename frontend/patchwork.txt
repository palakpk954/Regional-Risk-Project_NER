PLACIFY AI - PATCHWORK (Minor Project Summary)

1) Project Intro (What this minor project is)
Placify AI is an offline-first Placement Intelligence and Simulation Engine for Indian college placement workflows.
It converts CSV/Google Sheet placement records into analytics, simulation scenarios, and decision-ready reports.
Goal: make placement data easy to import, clean, understand, and present.

2) What Placify AI does end-to-end
Upload -> Parse -> Clean -> Engine -> Dashboard -> Simulator -> Report
- Migration page imports CSV or public Google Sheet links.
- Engine computes placement KPIs, branch/company insights, CGPA correlation, and at-risk students.
- Dashboard visualizes real metrics and auto-generated insights.
- Simulator runs what-if scenarios (CGPA threshold + branch filter) with live delta.
- Reports export aligned summary of baseline + simulation + AI-style insight blocks.

3) Old vs New (today's real patchwork)
OLD (before patchwork)
- Migration preview looked like it only read 10/12 rows.
- Data looked partially visible, causing confusion during demos.
- Company intelligence visibility was limited across pages.

NEW (after patchwork)
- Migration now stores full cleaned imported dataset in state.
- Pagination added (25/50/100/200) so all rows are testable.
- Counters now show: raw rows, cleaned rows, and visible range.
- Engine is canonical source for dashboard/simulator/report.
- Auto tech-company intelligence integrated with 4000+ signature catalog.
- Real-time feel improved with heartbeat + last-run elapsed timing.

4) What is working now (verified)
- CSV parsing with header normalization and strict validation.
- Google Sheets gviz JSON import with public-link checks.
- Data cleaning: empty-row removal, cgpa conversion, status normalization, dedupe.
- Accurate engine metrics and sorted chart-ready outputs.
- Simulator baseline/new rate/delta consistency.
- Report values aligned with on-screen dashboard/simulator values.
- Large demo CSV support (Indian college based, complex rows).

5) What is automatic now
- Automatic header mapping (name/email/cgpa/branch/company/status variants).
- Automatic status normalization to Selected/Interview/Applied.
- Automatic dedupe by identity with selected-priority update.
- Automatic chart and KPI refresh after import.
- Automatic simulation recompute on control change.
- Automatic top-tech company detection and confidence scoring.
- Automatic report text generation from current engine snapshot.

7) Why the “10 rows only” issue happened
- Earlier preview intentionally sliced rows for display speed.
- Processing was happening for full data, but UI gave wrong impression.
- Fixed by keeping full cleaned rows + pagination + explicit counters.
